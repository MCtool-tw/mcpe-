基岩版藍圖材質包生成器

匯入 .litematic、.schem、.nbt（Java）或 .mcstructure（基岩版），轉成放置盔甲座就顯示藍圖的資源包

所需材料清單
自訂紋理對照（修正洋紅黑格）

每行一筆「方塊名=貼圖路徑」，填 1 個路徑＝全部面，填 3 個（頂,底,側）可分面；路徑可省略 textures/blocks/。重新按「產生材質包」後生效。

封包資訊：圖示、作者、版本、說明

圖片會自動置中裁成正方形，輸出為 256×256 的 pack_icon.png。

藍圖顯示方式

勾選後，產生時會從官方範例庫下載用到的貼圖，另存成 7 種不透明度（40%～100%）放進資源包，遊戲內 [變淡]／[變濃] 改成直接換貼圖，最穩定。需要連網、封包會大一些，且內含官方貼圖的副本（請只供自己使用，勿轉發或販售）。取消勾選則不下載、不內含官方貼圖，但透明度只靠顏色設定，部分版本可能沒有效果。

遊戲內 [控制] 面板可隨時用 [變淡]／[變濃] 調整不透明度（40%～100%）、調整圖層與位置；這裡只是預設值。

遊戲內 [藍圖]／[控制] 按鈕位置

預設在畫面右上角、切換視角按鈕的左邊。位置不對或和其他按鈕重疊時，改這幾個數字再重新產生（單位是遊戲 UI 點數，不是像素；距邊緣越大，越往畫面中間移）。

沒有跳出儲存視窗時，請用 Safari／Chrome 開啟這個 HTML 檔再操作。

創造放置包（行為包，另外下載）

另外產生一個「行為包」：創造模式、且有指令權限的玩家，把指令方塊放進盔甲座手上，就會在藍圖的位置直接生成整棟建築。盔甲座命名牌填 L3 只放第 3 層；盔甲座的朝向、上面「藍圖顯示方式」的原點、以及匯入後的旋轉／鏡像都會一起套用。

需要較新的基岩版（腳本 API 2.1.0 以上）。箱子內容、告示牌文字、旗幟與床的顏色等「方塊實體資料」不會複製；水／岩漿與空氣不會放。找不到對應基岩版方塊的會略過，並在聊天室列出名稱。

使用方式
  1. 匯入藍圖後按「產生材質包」，開啟下載的 .mcpack 匯入遊戲，並在世界中啟用（排在最上層）。
  2. 放置盔甲座，藍圖就會出現。藍圖的 (0,0,0) 角落＝盔甲座所在方塊，盔甲座朝南時方向與原圖相同。
  3. 遊戲畫面右上角（切換視角按鈕左邊）有兩個按鈕：[藍圖] 開／關可捲動的材料清單（滿 64 個會顯示「N = S組+R」）；[控制] 開／關控制面板：顯示、圖層 ±、模式（只顯示單層／顯示該層以下）、變淡／變濃（調整透明度：變淡＝更透明、變濃＝更不透明）、東西南北上下微調位置、重置。電腦版：按住 Tab 看材料清單、↑／↓ 切換圖層。按鈕位置可在「遊戲內 [藍圖]／[控制] 按鈕位置」調整。
  4. 分層顯示：用 [控制] 的「層-／層+」，或用命名牌把盔甲座命名為 L1、L2… 只顯示該層；不命名＝顯示全部。
  5. 階梯、半磚、門、活板門、柵欄、牆、玻璃片、梯子、火把等會依方塊屬性畫出對應形狀；草、花、樹苗、蠟燭等小型裝飾不會畫出來，但仍會列在材料清單。旋轉／鏡像時方塊朝向會一起轉。
  6. 基岩版沒有的方塊會顯示錯誤紋理（洋紅黑格）。預設紋理直接引用遊戲內建資源，不內含任何官方素材；若勾選「遊戲內可調透明度」，資源包會內含從官方範例庫下載、調整過透明度的貼圖副本（只供個人使用，請勿轉發或販售）。
  7. 盔甲座沒放正（轉了角度）或站在半磚上，藍圖會自動對齊最近的 90° 方向與整數高度。
  8. 創造放置：另外下載「創造放置包」（行為包）並啟用。創造模式且有指令權限的玩家，把指令方塊放進盔甲座手上，就會在藍圖位置生成建築；要在盔甲座旁放藍圖資源包預覽時，兩個包可同時啟用。
  9. 控制與版面做法參考 HoloPrint（SuperLlama88888，CC BY-NC-SA 4.0）。
  10. 匯入後可旋轉／鏡像藍圖；點預覽圖可查方塊名稱；洋紅黑格可在「自訂紋理對照」填入基岩版貼圖路徑修正。
